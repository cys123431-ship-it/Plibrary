# PLibrary

배재대학교 통합 전자책 도서관(`https://ebook.pcu.ac.kr/FxLibrary/`)에서 공급처별 전자책 열람/대출 시간을 측정하는 Windows + Microsoft Edge 전용 도구입니다.

## 측정 기준

모든 공급처의 **종료 시점은 책 표지가 실제로 화면에 표시되는 순간**입니다.

| 공급처 | 시작 시점 | 자동 처리 | 종료 시점 |
|---|---|---|---|
| 교보문고 | `책읽기` 클릭 | 새 브라우저 창 감지 | 표지 표시 |
| 북큐브 | `책읽기` 클릭 | `웹 뷰어보기` 자동 클릭 | 표지 표시 |
| 알라딘 | `책읽기` 클릭 | `뷰어로 보기` 자동 클릭 → Windows 뷰어/다운로드 감지 | 최종 새 창의 표지 표시 |
| 우리전자책 | `책읽기` 클릭 | 새 브라우저 창 감지 | 표지 표시 |
| 웅진(OPMS) | `대출하기` 클릭 | 대출 완료 `확인` 자동 처리 | 새 창의 표지 표시 |
| 북레일(누리미디어) | `대출하기` 클릭 | 대출 완료 `확인` 자동 처리 | 새 창의 표지 표시 |

북레일(누리미디어)은 현재 현장 측정 도서인 **`내 삶의 길`**을 기본 검색어로 넣습니다.

## 사용 방법

1. Release에서 `PLibrary.exe`를 내려받아 실행합니다.
2. `1. Edge 열기 / 로그인`을 누릅니다. 프로그램 전용 Edge 프로필을 사용하므로 처음 한 번 배재대학교 전자책 도서관에 로그인합니다.
3. 교보문고/북큐브/알라딘/우리전자책은 모바일에서 대여한 책이 PC에 보이는 화면까지 준비합니다.
4. 웅진(OPMS)/북레일(누리미디어)은 공급처와 도서명을 선택합니다. 검색은 측정 시간에 포함되지 않고, 실제 `대출하기` 클릭부터 측정합니다.
5. `2. 측정 시작`을 누르면 공급처별 중간 버튼을 자동으로 처리하고 표지가 표시되면 자동 종료합니다.
6. 결과는 `%USERPROFILE%\Documents\PLibrary\measurements.csv`에 누적 저장됩니다.

자동 표지 감지가 특정 공급처 UI 개편 때문에 실패하면 측정 중 `표지 감지 수동 종료`를 누를 수 있습니다. 이 버튼은 예외 상황용이며 기본 동작은 자동 감지입니다.

## 개발

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONPATH="src"
pytest -q
python -m plibrary
```

Windows 실행 파일:

```powershell
pyinstaller PLibrary.spec --noconfirm
```

## 주의

- 로그인 아이디/비밀번호를 코드에 저장하지 않습니다. 로그인 쿠키 등은 로컬의 PLibrary 전용 Edge 프로필에만 남습니다.
- 공급처 사이트/뷰어의 버튼 문구 또는 화면 구조가 바뀌면 selector 조정이 필요할 수 있습니다.
- 측정 정확도를 위해 측정 중에는 해당 Edge/뷰어 창을 최소화하지 않는 것을 권장합니다.
